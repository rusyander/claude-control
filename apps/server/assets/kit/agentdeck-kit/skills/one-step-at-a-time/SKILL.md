# One step at a time

1. Write a plan of at most five lines: which files change and why.
2. Take the first file: read the part you will change, edit it, run the check that covers it.
3. Only then move to the next file. Update the plan if a step revealed something new.
4. Finish with the full project check (skill `agentdeck-kit:verify-by-running`).
