# Чего панель не делает

Разбор по разделам: что ограничено, почему и стоит ли этого ждать.

Список сверен с кодом, а не написан по памяти. У каждого пункта помечено, из
чего он растёт:

- **замысел** — так задумано, менять не планируется;
- **чужое** — ограничение самого Claude Code, операционной системы или сети;
- **задел** — стоит сделать, руки не дошли;
- **шероховатость** — ведёт себя не так, как ожидается, и это стоит исправить.

## Общее

| Что                                                           | Почему                                                                                                                               |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Изменения применяются после перезапуска Claude Code           | **чужое.** CLI читает конфигурацию при старте. Панель помечает такие правки, но перечитать чужой процесс не может                    |
| Один каталог конфигурации за раз                              | **замысел.** Панель работает с тем `~/.claude`, который нашла; проектные `.claude/settings.json` и `.mcp.json` она не ведёт          |
| Нет своей базы данных, истории и синхронизации между машинами | **замысел.** Источник правды — файлы Claude Code. История версий — это git, а не панель                                              |
| API без аутентификации, только `127.0.0.1`                    | **замысел.** Однопользовательский инструмент для своей машины. Выставлять наружу нельзя: кто дотянулся — читает токены и заводит хук |

## Обзор

| Что                                                                   | Почему                                                                     |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Страница только показывает, ничего не правит                          | **замысел.** Витрина; правки живут в разделах                              |
| Нет истории «что изменилось со вчера»                                 | **замысел.** Панель не ведёт своей базы                                    |
| Упавший MCP-сервер не подсвечен так же тревожно, как сломанный хук    | **шероховатость.** Число упавших считается, но тон плитки остаётся обычным |
| Ничего не известно про резервные копии — их видно только в настройках | **задел**                                                                  |

## Аналитика

| Что                                                        | Почему                                                                                                     |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Остаток лимитов подписки недоступен                        | **чужое.** Он на серверах Anthropic и в локальные файлы не попадает                                        |
| Стоимость — оценка, а не счёт                              | **замысел.** Пересчёт токенов по тарифам из настроек. Тарифы ведутся вручную: не обновили — оценка поехала |
| Актуальные цены не подтягиваются из сети                   | **замысел.** Раздел работает офлайн, сеть панель не трогает                                                |
| Выгрузки отчёта нет — ни CSV, ни JSON                      | **задел**                                                                                                  |
| Учитывается только эта машина и текущий каталог            | **замысел**                                                                                                |
| Огромные транскрипты читаются частями                      | **замысел.** Компромисс ради скорости: числа по таким файлам приблизительные                               |
| У «работающих агентов» нет времени старта на macOS и Linux | **чужое.** `ps` его не отдаёт, отдельный вызов ради одной колонки не оправдан                              |
| Агенты определяются по командной строке                    | **замысел.** Эвристика: переименованный бинарник или обёртка в список не попадут                           |

## Чат

| Что                                                                   | Почему                                                                                  |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Счётчик расхода за сессию обнуляется при перезагрузке                 | **шероховатость.** Сам прогон перезагрузку переживает, а счётчик живёт в памяти вкладки |
| Прогон, завершившийся при закрытой странице, в ленту не вернётся      | **замысел.** Буфер держится минуту; результат остаётся в транскрипте                    |
| Ветвления разговора нет: правка сообщения копирует текст в поле ввода | **задел.** `--fork-session` в рантайме уже прокинут, интерфейса нет                     |
| Разговоры нельзя удалять и переименовывать                            | **замысел.** Транскрипты принадлежат Claude Code, панель их только читает               |
| Поиск идёт по заголовку, проекту и превью, не по телу переписки       | **замысел.** Полнотекстового индекса нет, транскрипты слишком велики                    |
| Показываются последние 400 сообщений                                  | **замысел.** Иначе длинный разговор не открыть                                          |
| Список созданных файлов есть только у чатов вне проекта               | **замысел.** В настоящем репозитории такой список бесполезен                            |
| Поштучные разрешения не работают в режиме полного доступа             | **замысел.** Там разрешено всё по определению                                           |

## Правила

| Что                                 | Почему                                                                             |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| Только личный `~/.claude/CLAUDE.md` | **замысел.** Правил уровня проекта панель не ведёт                                 |
| Приоритетов между правилами нет     | **чужое.** Claude читает файл целиком; противоречие двух правил панель не разрешит |
| История — это копии файла целиком   | **замысел.** Откат вернёт весь `CLAUDE.md` того момента, а не одно правило         |
| Исполнение не гарантируется         | **чужое.** Правило — инструкция. Для гарантий есть права и хуки                    |

## Скиллы

| Что                                                     | Почему                                                                                                      |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Переименования нет                                      | **чужое.** Имя скилла — имя папки и его идентификатор                                                       |
| Удалённый скилл кнопкой не вернуть                      | **задел.** Копия папки в `claude-control/backups` есть, но откат умеет возвращать только файлы конфигурации |
| Путь к сделанной копии в интерфейсе не показывается     | **шероховатость.** Сервер его возвращает, интерфейс не отображает                                           |
| Версий и истории правок нет                             | **замысел.** Для этого скилл кладут в git                                                                   |
| Заранее не известно, подключится ли скилл               | **чужое.** Решает модель по описанию; проверяется прогоном в песочнице                                      |
| Вложенные файлы читаются только по ссылке из `SKILL.md` | **чужое.** Обхода папки у Claude Code нет                                                                   |

## Хуки

| Что                                                         | Почему                                                                                       |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Порядок выполнения внутри события не задаётся               | **задел.** Порядок равен порядку записей в файле, перестановки в интерфейсе нет              |
| Два полностью одинаковых хука различаются только суффиксом  | **замысел.** Идентификатор считается от содержимого; полные дубли неразличимы по определению |
| Правка команды меняет идентификатор хука                    | **замысел.** Это уже другая запись: сохранённая ссылка перестанет открываться                |
| Локальный хук нельзя выключить тумблером                    | **замысел.** Выключение здесь означало бы удаление строки из личного файла                   |
| Останавливать действие умеют только два события из девяти   | **чужое.** Ограничение Claude Code                                                           |
| Пошаговой отладки нет — только прогон, вывод и код возврата | **замысел**                                                                                  |
| Снимок выключенного хука живёт в `state.json` панели        | **замысел.** Потеря этого файла означает потерю выключенных хуков                            |

## Скрипты

| Что                                                  | Почему                                                                             |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `.ts` в песочнице запускается через bash             | **шероховатость.** Расширение числится поддержанным, но такой скрипт не отработает |
| `.ps1` вне Windows требует установленного `pwsh`     | **чужое.** Без него прогон невозможен; панель говорит об этом прямо                |
| Вложенные папки в `hooks/` не видны                  | **шероховатость.** Каталог читается плоско                                         |
| «Используется» определяется по имени файла в команде | **замысел.** Одноимённые файлы и косвенные вызовы определяются неверно             |
| Установки зависимостей и запуска по расписанию нет   | **замысел.** Скрипт получает то, что уже есть в системе; расписание — не про хуки  |

## Плагины

| Что                                                       | Почему                                                                       |
| --------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Маркетплейс нельзя подключить или убрать                  | **задел.** Список читается как есть; источники добавляются командой `claude` |
| Плагин нельзя собрать, отредактировать или взять частично | **замысел.** Содержимое принадлежит автору                                   |
| Всё упирается в CLI: нет `claude` — раздел мёртв          | **чужое.** Страница целиком обёртка над `claude plugin`                      |
| Любая операция блокирует страницу                         | **замысел.** Команды плагинов нельзя запускать вперемешку                    |
| Без сети не работает                                      | **чужое**                                                                    |

## MCP-серверы

| Что                                                   | Почему                                                                                         |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Интерактивный OAuth не поддержан                      | **задел.** Рукопожатие идёт с тем, что уже есть в заголовках; сервер с редиректом не проверить |
| Только глобальный `~/.claude.json`                    | **замысел.** Проектный `.mcp.json` панель не читает                                            |
| Отдельные инструменты сервера не включаются           | **чужое.** Сервер подключается целиком; отбор делается правами                                 |
| Проверка связи не запускается сама                    | **замысел.** Поднять сервер стоит времени                                                      |
| Таймауты фиксированы: 45 секунд у stdio, 10 у сетевых | **замысел.** Настройки в форме нет: медленный сетевой сервер будет объявлен недоступным        |
| Секреты сервера попадают в общий `~/.claude.json`     | **замысел.** Значения держат в разделе «Переменные»                                            |

## Права

| Что                                                                  | Почему                                                                             |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Право нельзя перенести между `settings.json` и `settings.local.json` | **замысел.** Файл записи определяется источником — иначе право тихо раздвоилось бы |
| Проектные `.claude/settings.json` не поддерживаются                  | **замысел.** Только пользовательский уровень                                       |
| Нельзя узнать, под какое правило попал конкретный запрос             | **чужое.** Панель пишет файл, но не читает решения CLI                             |
| Шаблон не проверяется на опечатку                                    | **задел.** Ошибка обнаружится только в работе                                      |
| Вкладка «Система» сверяет шаблоны буквально                          | **замысел.** `Bash(git push:*)` и `Bash(git push origin:*)` — разные вещи          |
| Приоритет решений фиксирован: deny > ask > allow                     | **чужое**                                                                          |

## Переменные

| Что                                           | Почему                                                                      |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| Переменную нельзя перенести между файлами     | **замысел.** Как и у прав, файл определяется источником                     |
| Значения не шифруются                         | **замысел.** Защита — права доступа на файл; ключ шифрования лежал бы рядом |
| Секрет при правке вводится заново             | **замысел.** Панель держит только маску                                     |
| Разделения по проектам нет                    | **замысел**                                                                 |
| Нельзя увидеть, что реально дошло до процесса | **чужое.** Панель пишет файлы, а не наблюдает окружение                     |
| Секрет определяется по имени переменной       | **замысел.** Списки слов у формы и сервера совпадают не полностью           |

## Группы

| Что                                       | Почему                                                                                                               |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Переменные группы не работают**         | **задел.** Поле сохраняется и показывается бейджем, но в `settings.json` не уходит: включение группы их не применяет |
| Вложенности групп нет                     | **замысел**                                                                                                          |
| Конфликты внутри группы не сверяются      | **задел.** Два участника с противоположными настройками панель не поймает                                            |
| Claude о группах не знает                 | **замысел.** Он видит только итоговые файлы                                                                          |
| Порядок обхода участников не задаётся     | **замысел.** Обход идёт в порядке хранения                                                                           |
| Сценарий не умеет больше, чем обычный хук | **замысел.** Он в хук и компилируется                                                                                |

## Настройки

| Что                                                               | Почему                                                                                  |
| ----------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Откат возвращает файл целиком                                     | **замысел.** Копия — снимок файла; выборочно вернуть одну настройку нельзя              |
| Восстанавливать можно только в пять известных файлов конфигурации | **замысел.** Защита: имя копии приходит из запроса и не должно становиться путём записи |
| Глубина ротации не настраивается — десять копий на файл           | **задел**                                                                               |
| Копии `.mcp-secrets.env` лежат открытым текстом                   | **замысел.** Ротация ограничивает накопление, но не устраняет                           |
| Тарифы правятся только для встроенных моделей                     | **задел.** Своя модель в список не добавляется                                          |
| Экспорта и импорта настроек панели нет                            | **задел**                                                                               |
| Входа в аккаунт и показа токена нет                               | **замысел.** Авторизацией занимается CLI; наружу отдаётся только источник доступа       |
