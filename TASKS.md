# Очередь работ

Только открытое. Разделено по тому, чем задача закрывается: **кодом** — берётся и делается сразу;
**живой проверкой** — код есть, но нужен настоящий запуск; **нужны вы** — действие, которое может
сделать только владелец. Сделанное и проверенное отсюда удаляется сразу, история — в коммитах.

> **Правило для всех UI-задач (владелец 27.09):** макеты и варианты не рисовать — сразу внедрять
> эталонное решение, красиво и удобно. Цвета и стиль устраивают; беда — пропадающее свободное место и
> нелепо стоящие элементы. Для подтверждения — один снимок уже переделанной страницы.

  3. Вердикт группы из блока «Тесты» на живом разделении: без прогона после старта группа получает
     напоминание с командой; с зелёным прогоном — «блок «Тесты»: зелёных N из M» в строке хаба.
  4. «Сделать кейс» в меню чата на настоящем разговоре и приёмка черновика в «Тестах».
  5. Агент чата на настоящей модели сам ведёт кейсы (`tests-cli case`) и записывает проверенное
     (`tests-cli record` или `run`); кейс человека — черновиком.
  6. Проверка набора поломкой на настоящем проекте (node_modules, своя команда прогона): отчёт
     «поймали / не заметили», рабочая копия и история нетронуты, копия убрана.
  7. Остановка фона по порту в переменной и `kill … || true` на настоящем ходе агента; MR группы по
     её ветке, когда голова совпала с предшественником.
  8. Сообщение агенту на ходу: на настоящей модели, посреди долгого хода (несколько вызовов
     инструментов) написать «ещё добавь X» — пузырь «Передано агенту», агент отвечает на ближайшем
     шаге и продолжает тот же ход; вопрос, отвеченный занятому агенту, — так же; с вложением — в
     очередь; после конца хода сообщение в ленте обычной репликой, не дублем; то же с телефона.
     Сообщение ровно в конце хода (шагов не осталось) — CLI начинает с ним новый ход сам.
- **Разделение на группы, живая приёмка.**
  1. Замечание ревью на настоящем MR уходит в сессию правки продолжением, а не новым чатом.
  2. Полное разделение на рабочем проекте до MR: группы сами коммитят, пушат и открывают MR.
  3. Вопрос группы виден в головном чате не позже 10 секунд — до перезапуска панели и после.
  4. «Завести» тикет создаёт настоящую задачу в трекере — одна пробная, по разрешению владельца.
  5. На песочнице: группа не уходит в продолжения за пределы своих файлов; шапка чата группы,
     открытого посреди хода, сразу показывает модель и «До MR»; после нового разделения у старых
     групп остаются «принято» и «Убрать копию»; после отмены плана вкладка не зовёт «агент ждёт».
  6. «Запустил и ушёл» — вместе с владельцем: он запускает разделение, агент наблюдает; мерило —
     сколько раз пришлось отвлечься. Сита перед MR проверяются тем же прогоном.
- **Агент панели на настоящей модели** — три примера владельца из плана партии «агент панели».
- **Блок «Тесты» на настоящем агенте** — генерация в черновик и приёмка, кнопки «исследовать» и
  «автоматизировать», прогон против намеренно сломанного экрана.
- **Телефон на устройстве** — холодный старт после конца прогона, переподключение после 30 с
  тишины, очередь и переподхват после перезапуска; тёмные кадры справки с самого телефона
  (day/offline, 12 из 15).
- **Чужие CLI: первая запись и первый разговор** — Aider, Cursor, OpenCode, Continue, Goose, Kimi
  Code. По одному: поставить CLI, записать из панели и сверить файл; задать два вопроса — ответ идёт
  потоком, второй помнит первый. OpenCode — ещё подъём `opencode serve` и падение в поток, а не в
  ошибку. Qwen — `UserPromptSubmit` под надзирателем панели срабатывает ровно один раз.
- **Перенос среды — живая проба по каждому CLI** (§9 [docs/TASKS-PORTABILITY.ru.md](docs/TASKS-PORTABILITY.ru.md)).
  Пробы для всех: хук блокирует · скилл срабатывает · право отказывает · MCP-инструмент виден ·
  переменная дошла · команда развернулась. Проба пройдена, если поведение совпало с уровнем из отчёта
  верности, **включая честный отказ** `×` с причиной. Особое:
  - Gemini: `yolo` записью не принимается — «право отказывает» показывает понижение до строгого.
  - Continue: запущенный без панели CLI видит ровно обещанное панелью, ни строкой больше.
  - Goose: нет своего адреса эндпоинта — «хук блокирует» возвращает отказ с причиной.
  - Kimi Code: блокируют только три события, блокирующий `PostToolUse` деградирует вслух; плагины
    только для чтения.
  - Cursor: панель его не запускает — половина проб обязана быть `×` с причиной.
  - OpenCode: сам читает `~/.claude/skills`; хуки только для чтения.
  - Aider: MCP нет — проба MCP `×` с причиной; инструкции — списком `read` в `.aider.conf.yml`.
- **macOS и Linux** — `which` и `PATH`, права `0600`/`0700`, запуск CLI без `cmd.exe`, связка ключей
