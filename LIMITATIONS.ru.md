# Чего панель не делает

Разбор по разделам: что ограничено, почему и стоит ли этого ждать.

Список сверен с кодом, а не написан по памяти. У каждого пункта помечено, из
чего он растёт:

- **замысел** — так задумано, менять не планируется;
- **чужое** — ограничение самого Claude Code, другого CLI, операционной системы
  или сети;
- **задел** — стоит сделать, адаптера пока нет.

> По разделам Claude Code пунктов «задел» и «шероховатость» (ведёт себя не так,
> как ожидается) в списке нет: всё, что было так помечено, доведено — от
> переменных групп и вложенных папок скриптов до интерактивного OAuth у
> MCP-серверов. История этих доработок — в [TASKS.md](TASKS.md). Пометка «задел»
> осталась только в разделе [«Другие CLI»](#другие-cli-мультипровайдерность):
> мультипровайдерность закрыта не полностью, и это честно перечислено ниже.

## Общее

| Что                                                           | Почему                                                                                                                                                                                                                                               |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Изменения применяются после перезапуска Claude Code           | **чужое.** CLI читает конфигурацию при старте. Панель помечает такие правки, но перечитать чужой процесс не может                                                                                                                                    |
| Один пользовательский каталог конфигурации за раз             | **замысел.** Панель работает с тем `~/.claude`, который нашла; проектный уровень (`CLAUDE.md`, `.mcp.json`, `.claude/settings.json` проекта) добавлен отдельно — в разделе «Проекты», но пока сыро: без групп, выключений, health, OAuth и песочницы |
| Нет своей базы данных, истории и синхронизации между машинами | **замысел.** Источник правды — файлы Claude Code. История версий — это git, а не панель                                                                                                                                                              |
| API без аутентификации, только `127.0.0.1`                    | **замысел.** Однопользовательский инструмент для своей машины. Выставлять наружу нельзя: кто дотянулся — читает токены и заводит хук                                                                                                                 |

## Обзор

| Что                                                    | Почему                                                                                                    |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Плитки только ведут в разделы, а не правят на месте    | **замысел.** Витрина; правки живут в разделах. Быстрые действия с плитки — это переход, а не правка здесь |
| Сводка «изменилось за N дней» считает по ленте истории | **замысел.** Число берётся из тех же копий, что и раздел «История», а не из отдельной базы правок         |

## Аналитика

| Что                                                        | Почему                                                                                                               |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Остаток лимитов подписки недоступен                        | **чужое.** Он на серверах Anthropic и в локальные файлы не попадает                                                  |
| Стоимость — оценка, а не счёт                              | **замысел.** Пересчёт токенов по прайсу: на подписке за токены не списывают, поэтому число читается как объём работы |
| Учитывается только эта машина и текущий каталог            | **замысел**                                                                                                          |
| Огромные транскрипты читаются частями                      | **замысел.** Компромисс ради скорости: числа по таким файлам приблизительные                                         |
| У «работающих агентов» нет времени старта на macOS и Linux | **чужое.** `ps` его не отдаёт, отдельный вызов ради одной колонки не оправдан                                        |
| Агенты определяются по командной строке                    | **замысел.** Эвристика: переименованный бинарник или обёртка в список не попадут                                     |

## Чат

| Что                                                                                    | Почему                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Прогон, завершившийся при закрытой странице, вернётся в ленту только в пределах минуты | **замысел.** Буфер держит завершённый прогон минуту: успели вернуться — лента догонит хвост; позже — результат остаётся только в транскрипте                                                                  |
| Разговоры нельзя удалять и переименовывать                                             | **замысел.** Транскрипты принадлежат Claude Code, панель их только читает                                                                                                                                     |
| Поиск по телу переписки есть, но с ограничениями                                       | **замысел.** Полнотекстовый поиск по сообщениям добавлен (переключатель «По сообщениям» в списке чатов); чтобы не читать гигантские транскрипты целиком, число совпадений и просматриваемых файлов ограничено |
| Лента открывается последними сообщениями, ранние подгружаются                          | **замысел.** Сразу показывается последнее окно, чтобы длинный разговор вообще открылся; кнопка «Загрузить ещё» подтягивает более ранние                                                                       |
| Список созданных файлов есть только у чатов вне проекта                                | **замысел.** В настоящем репозитории такой список бесполезен                                                                                                                                                  |
| Поштучные разрешения не работают в режиме полного доступа                              | **замысел.** Там разрешено всё по определению                                                                                                                                                                 |

## Правила

| Что                                                        | Почему                                                                                                                                           |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Раздел «Правила» ведёт только личный `~/.claude/CLAUDE.md` | **замысел.** Правила уровня проекта живут в отдельном разделе «Проекты» (правка `CLAUDE.md` проекта); групп, выключений и песочницы там пока нет |
| Приоритетов между правилами нет                            | **чужое.** Claude читает файл целиком; противоречие двух правил панель не разрешит                                                               |
| История — это копии файла целиком                          | **замысел.** Откат вернёт весь `CLAUDE.md` того момента, а не одно правило                                                                       |
| Исполнение не гарантируется                                | **чужое.** Правило — инструкция. Для гарантий есть права и хуки                                                                                  |

## Скиллы

| Что                                                     | Почему                                                                 |
| ------------------------------------------------------- | ---------------------------------------------------------------------- |
| Версий и истории правок нет                             | **замысел.** Для этого скилл кладут в git                              |
| Заранее не известно, подключится ли скилл               | **чужое.** Решает модель по описанию; проверяется прогоном в песочнице |
| Вложенные файлы читаются только по ссылке из `SKILL.md` | **чужое.** Обхода папки у Claude Code нет                              |

## Хуки

| Что                                                         | Почему                                                                                       |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Два полностью одинаковых хука различаются только суффиксом  | **замысел.** Идентификатор считается от содержимого; полные дубли неразличимы по определению |
| Правка команды меняет идентификатор хука                    | **замысел.** Это уже другая запись: сохранённая ссылка перестанет открываться                |
| Локальный хук нельзя выключить тумблером                    | **замысел.** Выключение здесь означало бы удаление строки из личного файла                   |
| Останавливать действие умеют только два события из девяти   | **чужое.** Ограничение Claude Code                                                           |
| Пошаговой отладки нет — только прогон, вывод и код возврата | **замысел.** Зато событие на входе — любое: девять заготовок или свой произвольный JSON      |
| Снимок выключенного хука живёт в `state.json` панели        | **замысел.** Потеря этого файла означает потерю выключенных хуков                            |

## Скрипты

| Что                                                            | Почему                                                                                                                                                            |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.ps1` вне Windows требует установленного `pwsh`               | **чужое.** Без него прогон невозможен; панель говорит об этом прямо                                                                                               |
| «Используется» определяется по имени файла в команде           | **замысел.** Одноимённые файлы и косвенные вызовы определяются неверно                                                                                            |
| Установки зависимостей и запуска по расписанию нет             | **замысел.** Скрипт получает то, что уже есть в системе; расписание — не про хуки                                                                                 |
| У провайдеров без хуков нет песочницы и отметки «используется» | **замысел.** Раздел работает у всех, но песочница поднимает Claude Code, а «используется» читается из хуков — у Codex, Gemini, Cursor, OpenCode и Aider этого нет |

## Плагины

| Что                                                            | Почему                                                                                                                       |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Установленный плагин нельзя отредактировать или взять частично | **замысел.** Содержимое принадлежит автору. Свой плагин можно завести скаффолдером, а содержимое установленного — посмотреть |
| Всё упирается в CLI: нет `claude` — раздел мёртв               | **чужое.** Страница целиком обёртка над `claude plugin`                                                                      |
| Любая операция блокирует страницу                              | **замысел.** Команды плагинов нельзя запускать вперемешку                                                                    |
| Без сети не работает                                           | **чужое**                                                                                                                    |

## MCP-серверы

| Что                                                    | Почему                                                                                                                                             |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Раздел «MCP» ведёт только глобальный `~/.claude.json`  | **замысел.** Проектный `.mcp.json` правится в разделе «Проекты» — там свой список MCP-серверов проекта, но без health-проверки, OAuth и выключений |
| Отдельные инструменты сервера не включаются            | **чужое.** Сервер подключается целиком; отбор делается правами                                                                                     |
| Проверка связи по умолчанию не запускается сама        | **замысел.** Поднять сервер стоит времени. В «Настройках» есть тумблер `mcpAutoCheck` — включает авто-проверку при открытии раздела                |
| Таймаут stdio фиксирован (45 с), сетевой настраивается | **замысел.** Сетевой таймаут задаётся в «Настройках» (`mcpNetworkTimeoutMs`, 2000–120000 мс); запуск локальных stdio-серверов ограничен жёстко     |
| Секреты сервера попадают в общий `~/.claude.json`      | **замысел.** Значения держат в разделе «Переменные»; OAuth-токены хранятся отдельно, файлом с правами 600                                          |

## Права

| Что                                                      | Почему                                                                                                                      |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Проектные `.claude/settings.json` — в отдельном разделе  | **замысел.** Права уровня проекта правятся в разделе «Проекты»; здесь, в разделе «Права», — только пользовательский уровень |

| Приоритет решений фиксирован: deny > ask > allow         | **чужое**                                                                                                                   |

| Что                                           | Почему                                                                      |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| Значения не шифруются                         | **замысел.** Защита — права доступа на файл; ключ шифрования лежал бы рядом |
| Секрет при правке вводится заново             | **замысел.** Панель держит только маску                                     |
| Разделения по проектам нет                    | **замысел**                                                                 |
| Нельзя увидеть, что реально дошло до процесса | **чужое.** Панель пишет файлы, а не наблюдает окружение                     |

## Проекты

| Что                                                                         | Почему                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Проектный уровень «сырой»: нет групп, выключений, health, OAuth и песочницы | **замысел.** Раздел добавлен аддитивно — правит `CLAUDE.md`, `.mcp.json` и `.claude/settings.json` проекта, но без надстроек пользовательского уровня                                                                                                                                                                                                                                                                                                                        |
| Проектные хуки в интерфейс пока не выведены                                 | **замысел.** Правятся только правила, MCP-серверы и права проекта                                                                                                                                                                                                                                                                                                                                                                                                            |
| Пользовательский уровень остаётся отдельным                                 | **замысел.** Разделы «Правила», «MCP» и «Права» по-прежнему ведут `~/.claude`; проектный уровень их не замещает                                                                                                                                                                                                                                                                                                                                                              |
| У прочих провайдеров проектный уровень уже, чем у Claude                    | **чужое.** Реестр проектов общий, но правится только задокументированное: инструкции проекта (`AGENTS.md`/`GEMINI.md`), проектный файл MCP (`.codex/config.toml`, `.gemini/settings.json`, `opencode.json`, `.cursor/mcp.json`), у Gemini ещё `.gemini/.env` и права в `.gemini/settings.json`, у Aider — `<проект>/.aider.conf.yml` (список `read` и `set-env`). Проектных хуков у них нет; у Cursor вместо файла инструкций проекта — каталог правил `.cursor/rules/*.mdc` |

## Группы

| Что                                       | Почему                                      |
| ----------------------------------------- | ------------------------------------------- |
| Claude о группах не знает                 | **замысел.** Он видит только итоговые файлы |
| Сценарий не умеет больше, чем обычный хук | **замысел.** Он в хук и компилируется       |

## Настройки

| Что                                                               | Почему                                                                                                                                                |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Восстанавливать можно только в пять известных файлов конфигурации | **замысел.** Защита: имя копии приходит из запроса и не должно становиться путём записи                                                               |
| Копии `.mcp-secrets.env` по умолчанию лежат открытым текстом      | **замысел.** Ротация ограничивает накопление. Есть опциональное шифрование (`encryptSecretBackups`, AES-256-GCM под паролем) — по умолчанию выключено |
| Входа в аккаунт и показа токена нет                               | **замысел.** Авторизацией занимается CLI; наружу отдаётся только источник доступа                                                                     |

## Другие CLI (мультипровайдерность)

Панель умеет настраивать не только Claude Code, но честная формулировка звучит
так: **универсально далеко не всё.** Полная карта «раздел × провайдер» — в
[README.ru.md](README.ru.md#другие-cli-кроме-claude); здесь — границы.

### Что есть только у Claude

| Что                                                                    | Почему                                                                                                                                                                       |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Скиллы, хуки, плагины/маркетплейсы, аналитика токенов, песочница-проба | **чужое.** Это не «мы не успели»: у других CLI таких сущностей либо нет вовсе, либо они устроены принципиально иначе. Переносить нечего, поэтому разделы просто скрыты       |
| Правила (`## ПРАВИЛО:` внутри `CLAUDE.md`)                             | **замысел.** Разбор файла на именованные секции с выключателем — соглашение этой панели поверх `CLAUDE.md`. У соседних CLI файл инструкций правится целиком, без такого слоя |
| Богатый чат: стриминг, вложения, голос, ветвление, параллельные агенты | **замысел.** Он построен на потоковом протоколе `claude` CLI. У остальных провайдеров — базовый экспериментальный ассистент, см. ниже                                        |
| История и поиск по всем разделам сразу                                 | **замысел.** У чужого провайдера в ленту и поиск попадают только его рабочие (`ready`) разделы — остальное панель не читает вовсе                                            |

### Ассистент у чужих провайдеров

| Что                                                                 | Почему                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| У Codex, Gemini и Aider ассистент базовый: один вопрос — один ответ | **задел.** Работает через задокументированный неинтерактивный запуск (`codex exec`, `gemini -p`, `aider --message`): без стриминга, вложений, истории и выбора глубины. Помечен как экспериментальный                                                                               |
| Ассистент Aider не проверен живым прогоном                          | **честно.** `aider` на машине разработки не установлен: раннер собран по документации (`--message <text>` — «отправить одно сообщение, обработать ответ и выйти») и покрыт тестами на форму argv, но реального запуска CLI не было. Первый настоящий вызов стоит посмотреть глазами |
| У OpenCode ассистента нет                                           | **задел.** Задокументированного one-shot-флага CLI у него не нашлось, а угадывать аргументы чужого CLI мы не будем — раздел остаётся заглушкой                                                                                                                                      |
| У Cursor ассистента нет и не будет                                  | **чужое.** У Cursor нет собственного модельного API, к которому панель могла бы обратиться напрямую                                                                                                                                                                                 |
| Ответ приходит целиком, без токен-за-токеном                        | **чужое.** Неинтерактивный режим чужих CLI отдаёт результат одним куском                                                                                                                                                                                                            |

### Незакрытые разделы по провайдерам

| Что                                                          | Почему                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cursor:** правило с непонятным frontmatter только читается | **замысел.** Правила Cursor — каталог `.mdc`-файлов, и панель их правит (глобально и в проекте). Но если frontmatter файла не разбирается или его нет вовсе, правило открывается только для чтения: переписывать разметку, которую панель не поняла, вслепую нельзя. Обычный `.md` в каталоге правил Cursor игнорирует — панель показывает такие файлы, но не трогает |
| **Aider:** инструкции устроены не как у Claude               | **чужое.** Единого файла инструкций у Aider нет: файлы контекста перечисляются опцией `read` в `.aider.conf.yml`. Панель поэтому правит **список ссылок** (добавить/убрать/переставить) и, отдельно, содержимое уже существующего перечисленного файла. Файлов «от себя» она не создаёт и не открывает то, на что конфиг не ссылается                                 |
| **Aider:** MCP-серверов нет вовсе                            | **чужое.** В справочнике опций Aider настройки MCP-серверов не существует — настраивать нечего, раздел скрыт                                                                                                                                                                                                                                                          |
| **Gemini:** режим `yolo` в правах недоступен                 | **чужое.** По документации Gemini это режим только для флага командной строки; записанный в `settings.json`, он валит запуск CLI ошибкой. Панель его не пишет и объясняет отказ — нужен такой режим, запускайте `gemini --yolo`                                                                                                                                       |
| **OpenCode:** переменные окружения и права — заглушка        | **задел.** Модель у него своя; адаптер не написан                                                                                                                                                                                                                                                                                                                     |
| **Все, кроме Claude:** проектный уровень урезан              | **задел + чужое.** У Codex и OpenCode правятся проектные инструкции и проектный файл MCP, у Gemini к ним добавлены переменные окружения и права проекта, у Cursor — `.cursor/mcp.json` и каталог правил `.cursor/rules/*.mdc`, у Aider — `<проект>/.aider.conf.yml` (список `read` + `set-env`). Проектных хуков нет ни у кого, кроме Claude                          |
| Раздел «в разработке» ничего не читает и не пишет            | **замысел.** Это fail-closed: заглушка вместо догадки о формате. Мутации из такого раздела не уходят                                                                                                                                                                                                                                                                  |
| Прочие CLI (Kimi, Qwen, Continue, Goose) не поддержаны       | **задел.** Каждый требует своего адаптера формата и отдельной верификации по документации                                                                                                                                                                                                                                                                             |

### Осторожность с чужими форматами

| Что                                                                          | Почему                                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Все провайдеры кроме Claude помечены `experimental`                          | **замысел.** Форматы взяты из документации каждого CLI и закрыты round-trip-тестами, но живьём проверен только путь Claude. Первую реальную запись в каждый впервые затрагиваемый чужой формат стоит проверить глазами (`verify-on-first-real-run`) |
| Битый или неожиданно устроенный чужой конфиг делает раздел только для чтения | **замысел.** Fail-closed: панель отвечает ошибкой, а не «дописывает наугад». Причина видна в интерфейсе                                                                                                                                             |
| Откат резервной копии чужого провайдера запрещён                             | **замысел.** Копии провайдера видны в истории и диффе, но восстановить из них — ни файл целиком, ни отдельное изменение — нельзя: возврат чужого конфига должен быть осознанным ручным действием                                                    |
| Переопределение каталога уважается не у всех                                 | **чужое.** Уважаются только задокументированные переменные: `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `XDG_CONFIG_HOME` (OpenCode). У Gemini, Cursor и Aider такой переменной не задокументировано — пути берутся от домашнего каталога                    |
| Мультипровайдерность прогонялась вживую только на Windows                    | **задел.** Код кроссплатформенный (`os.homedir()`, `path.join`, имена CLI и `where`/`which` покрыты тестами с подменой платформы), но живого прогона на macOS и Linux не было — см. ниже                                                            |

## Поддержка систем

| Что                                           | Почему                                                                      |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| `.ps1`-хуки вне Windows требуют `pwsh`        | **чужое**                                                                   |
| Время старта агентов только на Windows        | **чужое**                                                                   |
| Учётные данные на macOS лежат в связке ключей | **чужое.** Первое обращение вызывает окно разрешения; подробности — в SETUP |

Отдельно и честно: **живьём панель прогонялась на Windows.** Ядро переносимо по
построению — домашний каталог всегда через `os.homedir()`, пути через
`path.join`, разбор текста одинаково терпит `\n` и `\r\n`, — а платформозависимые
места (имена исполняемых файлов CLI, `where` против `which`, обёртка запуска
процесса) покрыты тестами с подменой `process.platform` на `win32`, `darwin` и
`linux`. Но тест с подменой платформы — не то же самое, что запуск на настоящей
системе. Не проверено вживую и остаётся под вопросом на macOS/Linux: реальный
`which` и реальные пути в `PATH`, права `0600`/`0700` на файлах ключей, запуск
CLI без обёртки `cmd.exe`, связка ключей macOS и чувствительность файловой
системы к регистру. Два теста, которым нужен настоящий POSIX (связка ключей и
`chmod 000`), помечены пропущенными, а не подделаны.
