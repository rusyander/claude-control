# Чего панель не делает у других CLI

Продолжение [«Чего панель не делает»](LIMITATIONS.ru.md) — часть про мультипровайдерность.
Пометки: **замысел** — так задумано; **чужое** — ограничение самого CLI; **честно** — работает, но
проверено не до конца; **задел** — стоит сделать, адаптера пока нет.

## Другие CLI (мультипровайдерность)

Панель настраивает не только Claude Code, но честная формулировка такая: **универсально далеко не
всё.** Карта «раздел × провайдер» — в [README.ru.md](../README.ru.md#другие-cli-кроме-claude),
детали форматов — в [PROVIDERS.ru.md](PROVIDERS.ru.md); здесь — границы.

### Что есть только у Claude

| Что                                                                      | Почему                                                                                                                                   |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Аналитика токенов, песочница, маркетплейсы плагинов                      | **чужое.** У других CLI таких сущностей либо нет, либо они устроены принципиально иначе — переносить нечего                              |
| Правила (`## ПРАВИЛО:` внутри `CLAUDE.md`)                               | **замысел.** Разбор файла на именованные секции — соглашение этой панели; у соседних CLI файл инструкций правится целиком                |
| Ход работы агента в чате: инструменты, шаги, стоимость, ветвление, голос | **замысел.** Всё это разбирается из потокового протокола `claude` CLI; у остальных CLI такого задокументированного формата нет ни у кого |
| История и поиск по всем разделам сразу                                   | **замысел.** У чужого провайдера в ленту и поиск попадают только его рабочие разделы                                                     |

Хуки, плагины и скиллы — исключение: они есть у OpenCode, Qwen Code и Kimi Code, но каждый в своей
модели, и сделаны отдельными разделами.

### Чат у чужих провайдеров

Разговоры, память между вопросами, ответ по мере печати, рабочий каталог и прикрепление файлов
работают у всех CLI, у которых задокументирован неинтерактивный запуск. Границы — ниже.

| Что                                                                           | Почему                                                                                                                                                                                                            |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Переписку ведёт панель, а не CLI                                              | **замысел.** У этих CLI своей читаемой истории либо нет, либо её формат не задокументирован. Разговоры лежат в файлах панели, и из панели же собирается контекст следующего вопроса                               |
| Показывается сырой вывод CLI, без разбора шагов и инструментов                | **чужое.** Потокового формата с шагами не публикует ни один из этих CLI; показывать что-то сверх напечатанных байтов значило бы придумывать за них формат                                                         |
| Длинный разговор урезается спереди (около 24 тысяч символов)                  | **чужое.** Промпт уезжает отдельным элементом командной строки, а она обрывается примерно на 32 тысячах символов; лучше отбросить старые реплики, чем молча отправить обрубок вопроса                             |
| Вложение — это путь к файлу, а не его содержимое                              | **замысел.** Агентские CLI читают файлы сами; вкладывать содержимое в промпт значило бы придумывать за них формат вложения                                                                                        |
| У OpenCode вместо запуска на вопрос держится сессия                           | **замысел.** Панель поднимает `opencode serve`, поэтому контекст не пересылается заново; ответ при этом приходит целиком, а не по мере печати, и заминка сервера роняет разговор обратно в поток одноразового CLI |
| Чаты Aider, OpenCode, Continue, Goose и Kimi Code не проверены живым прогоном | **честно.** Эти CLI на машине разработки не установлены: запуск собран по документации и покрыт тестами на форму argv                                                                                             |
| У Cursor чата нет и не будет                                                  | **чужое.** У Cursor нет ни неинтерактивного запуска, ни собственного модельного API                                                                                                                               |

### Незакрытые разделы по провайдерам

Что именно правится у каждого CLI — в [PROVIDERS.ru.md](PROVIDERS.ru.md); ниже только границы.

| Что                                                                                | Почему                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Cursor:** правило с непонятым frontmatter только читается                        | **замысел.** Переписывать вслепую разметку, которую панель не разобрала, нельзя; обычный `.md` Cursor в каталоге правил игнорирует                                                                                                                                                                                 |
| **Aider:** MCP-серверов нет вовсе                                                  | **чужое.** В справочнике опций Aider настройки MCP не существует — настраивать нечего                                                                                                                                                                                                                              |
| **Gemini:** режим `yolo` недоступен                                                | **чужое.** По документации это флаг командной строки; в `settings.json` он валит запуск CLI. Нужен такой режим — запускайте `gemini --yolo`                                                                                                                                                                        |
| **OpenCode:** переменных окружения нет вовсе                                       | **чужое.** Хранить их негде: OpenCode читает уже заданное окружение процесса и своего `.env` не загружает                                                                                                                                                                                                          |
| **OpenCode:** непонятые записи в `permission` только читаются                      | **замысел.** Запись, формат которой панель не ведёт, остаётся как есть; переопределения `agent.*` не трогаются вовсе                                                                                                                                                                                               |
| **OpenCode:** хуки только для чтения                                               | **чужое.** Ключ `experimental.hook` исчез и из справочника конфигурации, и из опубликованной схемы, а сам `experimental` в ней закрыт для чужих ключей. Панель показывает то, что уже лежит в файле, но писать перестала; задокументированный способ повесить действие на событие у OpenCode теперь один — плагины |
| **OpenCode:** событий хуков ровно два                                              | **чужое.** Задокументированы только `file_edited` и `session_completed`; придумывать события панель не станет                                                                                                                                                                                                      |
| **OpenCode:** команда хука — список аргументов                                     | **чужое.** Действие запускается без оболочки: конвейеры, `&&`, подстановки и перенаправления не работают — нужен shell, вызывайте его первым аргументом                                                                                                                                                            |
| **OpenCode:** плагины из npm не устанавливаются                                    | **замысел.** Ключ `plugin` — только список имён; скачиванием занимается сам CLI                                                                                                                                                                                                                                    |
| **OpenCode:** скиллы Claude раздел показывает, но не трогает                       | **честно.** OpenCode грузит их из `~/.claude/skills` и `~/.agents/skills`; ими ведает собственный раздел Claude                                                                                                                                                                                                    |
| **Везде:** раздел «Команды» только читает                                          | **замысел.** Список сводит четыре источника в одну витрину; правка идёт в разделе скиллов или плагинов, файлы команд панель не пишет ни у одного CLI                                                                                                                                                               |
| **Codex, Continue, Goose, Kimi Code, Cursor, Aider:** раздела «Команды» нет        | **чужое.** Формат пользовательских слэш-команд у них не описан в документации; изобретать его панель не станет                                                                                                                                                                                                     |
| **Все, кроме Claude:** проектный уровень урезан                                    | **задел + чужое.** Правится только то, что задокументировано у каждого CLI                                                                                                                                                                                                                                         |
| Раздел «в разработке» ничего не читает и не пишет                                  | **замысел.** Fail-closed: заглушка вместо догадки о формате                                                                                                                                                                                                                                                        |
| **Qwen Code:** событие хука с непонятой формой становится только чтением           | **замысел.** Fail-closed: группа с двумя действиями, действие не типа `command` или чужое поле — и панель сохраняет это событие целиком как есть, остальные правятся                                                                                                                                               |
| **Qwen Code:** одно действие на группу хука                                        | **замысел.** Панель ведёт форму «событие → матчер → команда»; список из нескольких действий она сохранит, но править не даст                                                                                                                                                                                       |
| **Continue:** глобальных инструкций нет вовсе                                      | **чужое + замысел.** Задокументирован только каталог правил проекта; ключ `rules:` конфига неоднороден (строки вперемешку со ссылками `uses:`), угадывать панель не станет                                                                                                                                         |
| **Continue:** новый сервер всегда попадает в `config.yaml`                         | **замысел.** Файлы-блоки `mcpServers/*.yaml` панель читает и правит там, где запись лежит, но своих не заводит: имя файла — решение человека                                                                                                                                                                       |
| **Continue:** блок со ссылкой `uses:` или чужой формы пропускается целиком         | **замысел.** Fail-closed пофайлово: такой файл панель не показывает и не трогает, называя его и причину; остальные блоки работают                                                                                                                                                                                  |
| **Continue:** глобальная папка блоков `~/.continue/mcpServers` не проверена живьём | **честно.** Документация описывает папку блоков в рабочей папке проекта; глобальную CLI сканирует тем же кодом, но на живом Continue панель этого не проверяла                                                                                                                                                     |
| **Continue:** комментарии внутри блока `mcpServers` не переживают запись           | **честно.** Блок пересобирается из значений — иначе не удержать сохранность чужих полей записи; комментарии вне блока целы                                                                                                                                                                                         |
| **Goose:** раздела переменных окружения нет                                        | **чужое + замысел.** Своего `.env` у Goose не бывает — ключи лежат в связке ключей ОС или в `secrets.yaml`, а секреты панель не ведёт                                                                                                                                                                              |
| **Goose:** `permission.yaml` показывается, но не правится                          | **чужое.** Формата этого файла в документации Goose нет: описаны лишь три уровня и путь настройки `goose configure`. Писать чужой формат по исходникам панель не станет — она показывает, что настроено, и отсылает к `goose configure`                                                                            |
| **Goose:** встроенные расширения не показываются и не пишутся                      | **замысел.** `developer`, `memory` и прочие — части самого CLI, а не MCP-серверы: запись, попадающая на такую запись, отклоняется                                                                                                                                                                                  |
| **Goose:** комментарии внутри правящейся записи расширения теряются                | **честно.** Запись пересобирается из значений, чтобы перенести немоделируемые поля (`timeout`, `cwd`, `env_keys`); всё вне записи цело                                                                                                                                                                             |
| **Kimi Code:** переменных окружения нет                                            | **чужое + замысел.** Своего `.env` он не читает: ключи провайдеров лежат в `config.toml`, а секреты панель в чужие конфиги не пишет                                                                                                                                                                                |
| **Kimi Code:** любое отклонение в `[[hooks]]` делает раздел только чтением         | **замысел.** Fail-closed: плоский массив таблиц TOML нельзя переписать частично, не потеряв чужие записи, поэтому под замок уходит весь раздел, а не одна запись                                                                                                                                                   |
| **Kimi Code:** проектных хуков нет                                                 | **чужое.** Проектного `config.toml` этот CLI не читает — хуки бывают только пользовательские                                                                                                                                                                                                                       |
| **Kimi Code:** плагины только для чтения                                           | **чужое + замысел.** Ставит, включает и выключает их сам CLI командой `/plugins`; формы реестра `plugins/installed.json` документация не описывает, а править состояние в обход — гадание                                                                                                                          |
| **Kimi Code:** проектных прав нет                                                  | **чужое.** CLI читает ровно один пользовательский `config.toml`; изоляция под проект делается подменой `KIMI_CODE_HOME`                                                                                                                                                                                            |
| **Kimi Code:** чужое поле в `[permission]` делает раздел только чтением            | **замысел.** Fail-closed: регенерировать блок с непонятым полем значило бы потерять чужие данные                                                                                                                                                                                                                   |

### Осторожность с чужими форматами

| Что                                                             | Почему                                                                                                                                                                                                        |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Все провайдеры кроме Claude помечены `experimental`             | **замысел.** Форматы из документации и round-trip-тестов, но живьём пройден только путь Claude: первую реальную запись стоит проверить глазами                                                                |
| Битый или неожиданный чужой конфиг делает раздел только чтением | **замысел.** Fail-closed: ошибка вместо «дописать наугад», причина видна в интерфейсе                                                                                                                         |
| Откат резервной копии чужого провайдера запрещён                | **замысел.** Копии видны в истории и диффе, но возврат чужого конфига должен быть осознанным ручным действием                                                                                                 |
| Переопределение каталога уважается не у всех                    | **чужое.** Только задокументированные: `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `XDG_CONFIG_HOME`, `OPENCODE_CONFIG`, `QWEN_HOME`, `KIMI_CODE_HOME`. У Gemini, Continue, Goose, Cursor и Aider такой переменной нет |
| Мультипровайдерность прогонялась вживую только на Windows       | **задел.** Код кроссплатформенный и покрыт тестами с подменой платформы, но живого прогона на macOS и Linux не было                                                                                           |
