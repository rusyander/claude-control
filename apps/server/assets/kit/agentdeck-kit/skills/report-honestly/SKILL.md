# Report honestly

1. Outcome first, in one or two sentences: done, partly done, or blocked.
2. What ran: the commands or checks, each with its result line as printed. Never a number that was not printed.
3. What was not checked and why (no stand, no access, no time). Unverified work is never called done.
4. Open questions that need the user's decision, each with a recommendation.
5. No walkthrough of every edit; the diff already shows it.
