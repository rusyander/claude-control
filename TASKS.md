## Нужны вы

- **Интеграции: перенос найденного одной кнопкой на вашей машине (В6, 10.10).** «Найти уже
  подключённые» на вашем `~/.claude.json` находит Jira и Confluence (сервер Atlassian в Docker),
  GitLab (npx) и Telegram — только маски ключей. Сам перенос агенту запрещён: он пишет ключ в ваше
  хранилище секретов. Ваш шаг: «Перенести выбранные». Jira и Confluence заменят сохранённое — сейчас
  в адресе Jira путь страницы (`…/secure/RapidBoard.jspa`), и ключ отклоняется (403); из MCP
  придут адреса сайтов без пути.
- **Локальная модель в настоящем VS Code — вместе (решено 10.10).** Вы включаете «Claude Code на
  этой модели», открываете новый чат Claude Code в VS Code и задаёте вопрос; агент по журналу шлюза
  подтверждает, что ответил Qwen; затем выключаете.
- **«Запустил и ушёл» — на следующей настоящей пачке задач (решено 10.10).** Вы запускаете
  разделение и говорите «запускаю»; агент наблюдает, считает, сколько раз панель вас отвлекла и
  почему, и исправляет лишние отвлечения.

## Телефон — потом (владелец 10.10)

Всё, что решается и проверяется на телефоне, — отдельным заходом, когда дойдём до оставшихся
исправлений. Кодовую часть можно готовить заранее, полноценная проверка на устройстве — тогда же.

- **🔴 Телефон не показывает агента.** На компьютере вопросы агента и ход видны, на телефоне в
  последних сборках активности нет вовсе: ни хода, ни вопросов. Воспроизвести на эмуляторе по API
  стенда, найти причину, исправить, проверить на свежем APK.
- **Отправка из телефона и перезапуск «чистой сессией»** запускают выбранный CLI с аргументами
  Claude — Qwen так не стартует. Сервер — малая правка; чат телефона через маршрут чужих CLI — большая.
- **Уведомления на телефон для чатов чужих CLI** — сейчас их нет.
- **Сообщение агенту на ходу с телефона** (партия 30.09, пункт 8).
- **Телефон на устройстве** — холодный старт после конца прогона, переподключение после 30 с
  тишины, очередь и переподхват после перезапуска; тёмные кадры справки с самого телефона
  (day/offline, 12 из 15).
- **Push на телефон (решено 10.10: нужно).** Вы заводите бесплатный проект Firebase (файл
  `google-services.json`) и аккаунт Expo (номер проекта) по инструкции агента; дальше подключение,
  сборка APK и проверка — агент.
