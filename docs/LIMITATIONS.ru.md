# Чего панель не делает

Разбор по разделам: что ограничено и почему. Список сверен с кодом. Две пометки: **замысел** — так
задумано; **чужое** — ограничение Claude Code, ОС или сети.

Границы по другим CLI — в отдельном файле
[LIMITATIONS-PROVIDERS.ru.md](LIMITATIONS-PROVIDERS.ru.md).

🔧 [Установка и починка](SETUP.ru.md) · 🔌 [Провайдеры: детали форматов](PROVIDERS.ru.md)

## Общее

| Что                                                    | Почему                                                                                                                   |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| Изменения применяются после перезапуска Claude Code    | **чужое.** CLI читает конфигурацию при старте; панель такие правки помечает, но перечитать чужой процесс не может        |
| Один каталог конфигурации за раз                       | **замысел.** Панель работает с найденным `~/.claude`; проектный уровень — отдельный раздел «Проекты», пока без надстроек |
| Нет своей базы, истории и синхронизации между машинами | **замысел.** Источник правды — файлы Claude Code, история версий — git                                                   |
| API без аутентификации, только `127.0.0.1`             | **замысел.** Однопользовательский инструмент; кто дотянулся — читает токены и заводит хук                                |

## Обзор

| Что                                                    | Почему                                                             |
| ------------------------------------------------------ | ------------------------------------------------------------------ |
| Плитки ведут в разделы, а не правят на месте           | **замысел.** Витрина; правки живут в разделах                      |
| Сводка «изменилось за N дней» считает по ленте истории | **замысел.** Число берётся из тех же копий, что и раздел «История» |

## Аналитика

| Что                                                        | Почему                                                                           |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Остаток лимитов подписки недоступен                        | **чужое.** Он на серверах Anthropic и в локальные файлы не попадает              |
| Стоимость — оценка, а не счёт                              | **замысел.** На подписке за токены не списывают; число читается как объём работы |
| Учитывается только эта машина и текущий каталог            | **замысел**                                                                      |
| Огромные транскрипты читаются частями                      | **замысел.** Компромисс ради скорости: числа по таким файлам приблизительные     |
| У «работающих агентов» нет времени старта на macOS и Linux | **чужое.** `ps` его не отдаёт                                                    |
| Агенты определяются по командной строке                    | **замысел.** Эвристика: переименованный бинарник или обёртка в список не попадут |

## Чат

Чат — самый большой раздел панели, и его границы описаны рядом с ним самим:
[Чат, вкладки и параллельные агенты § Чего чат не делает](CHAT.ru.md#чего-чат-не-делает) — прогон,
закончившийся при закрытой странице, разговоры без удаления и переименования, git проекта без
слияния и разбора конфликтов, параллельные копии, потолки разбивки задач и правила продолжения в
чистой сессии.

## Правила

| Что                                                        | Почему                                                                                |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Раздел «Правила» ведёт только личный `~/.claude/CLAUDE.md` | **замысел.** Правила проекта — в разделе «Проекты», без групп, выключений и песочницы |
| Приоритетов между правилами нет                            | **чужое.** Claude читает файл целиком; противоречие двух правил панель не разрешит    |
| История — это копии файла целиком                          | **замысел.** Откат вернёт весь `CLAUDE.md` того момента, а не одно правило            |
| Исполнение не гарантируется                                | **чужое.** Правило — инструкция; для гарантий есть права и хуки                       |

## Скиллы

| Что                                                     | Почему                                                                 |
| ------------------------------------------------------- | ---------------------------------------------------------------------- |
| Версий и истории правок нет                             | **замысел.** Для этого скилл кладут в git                              |
| Заранее не известно, подключится ли скилл               | **чужое.** Решает модель по описанию; проверяется прогоном в песочнице |
| Вложенные файлы читаются только по ссылке из `SKILL.md` | **чужое.** Обхода папки у Claude Code нет                              |

## Команды

| Что                                                    | Почему                                                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| Раздел ничего не правит                                | **замысел.** Это витрина: правка идёт в разделе скиллов или плагинов, куда ведёт кнопка        |
| Запустить команду отсюда нельзя                        | **замысел.** Вызов остаётся за чатом и CLI                                                     |
| Список встроенных команд ведёт панель                  | **чужое.** CLI не умеет перечислять свои команды наружу; свежая команда появится с обновлением |
| Чужие описания не переводятся                          | **замысел.** Описание скилла или плагина показывается ровно так, как написано в файле          |
| Группы считаются по имени и владельцу, а не по замыслу | **замысел.** Общее начало имени или один плагин — единственные признаки, которые видны с диска |

## Хуки

| Что                                                         | Почему                                                                        |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Полные дубли различаются только суффиксом                   | **замысел.** Идентификатор считается от содержимого                           |
| Правка команды меняет идентификатор                         | **замысел.** Это уже другая запись: сохранённая ссылка перестанет открываться |
| Локальный хук нельзя выключить тумблером                    | **замысел.** Выключение означало бы удаление строки из личного файла          |
| Останавливать действие умеют только два события из девяти   | **чужое.** Ограничение Claude Code                                            |
| Пошаговой отладки нет — только прогон, вывод и код возврата | **замысел.** Зато событие на входе любое: девять заготовок или свой JSON      |
| Снимок выключенного хука живёт в `state.json` панели        | **замысел.** Потеря файла означает потерю выключенных хуков                   |

## Скрипты

| Что                                                            | Почему                                                                           |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `.ps1` вне Windows требует установленного `pwsh`               | **чужое.** Панель говорит об этом прямо                                          |
| «Используется» определяется по имени файла в команде           | **замысел.** Одноимённые файлы и косвенные вызовы определяются неверно           |
| Установки зависимостей и запуска по расписанию нет             | **замысел.** Скрипт получает то, что уже есть в системе                          |
| У провайдеров без хуков нет песочницы и отметки «используется» | **замысел.** Песочница поднимает Claude Code, а «используется» читается из хуков |

## Плагины

| Что                                                                          | Почему                                                                                                                                                                                  |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Установленный плагин нельзя отредактировать или взять частично               | **замысел.** Содержимое принадлежит автору; свой заводится скаффолдером                                                                                                                 |
| Всё упирается в CLI: нет `claude` — раздел мёртв                             | **чужое.** Страница целиком обёртка над `claude plugin`                                                                                                                                 |
| Любая операция блокирует страницу                                            | **замысел.** Команды плагинов нельзя запускать вперемешку                                                                                                                               |
| Без сети не работает                                                         | **чужое**                                                                                                                                                                               |
| Плагин, поставленный мимо панели, попадает в общий поиск в течение полминуты | **замысел.** Список установленного отдаёт CLI (полсекунды на запуск), и поиск держит его кэш 30 секунд; в самом разделе плагин виден сразу, а операции панели сбрасывают кэш немедленно |

## MCP-серверы

| Что                                                    | Почему                                                                                                  |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Раздел ведёт только глобальный `~/.claude.json`        | **замысел.** Проектный `.mcp.json` правится в «Проектах» — без health-проверки, OAuth и выключений      |
| Отдельные инструменты сервера не включаются            | **чужое.** Сервер подключается целиком; отбор делается правами                                          |
| Проверка связи сама не запускается                     | **замысел.** Поднять сервер стоит времени; тумблер `mcpAutoCheck` в «Настройках» включает авто-проверку |
| Таймаут stdio фиксирован (45 с), сетевой настраивается | **замысел.** Сетевой — `mcpNetworkTimeoutMs`, 2000–120000 мс                                            |
| Секреты сервера попадают в общий `~/.claude.json`      | **замысел.** Значения держат в «Переменных»; OAuth-токены лежат отдельно, файлом с правами 600          |

## Права

| Что                                                      | Почему                                                                    |
| -------------------------------------------------------- | ------------------------------------------------------------------------- |
| Проектные `.claude/settings.json` — в разделе «Проекты»  | **замысел.** Здесь только пользовательский уровень                        |
| Нельзя узнать, под какое правило попал конкретный запрос | **чужое.** Панель пишет файл, но не читает решения CLI                    |
| Вкладка «Система» сверяет шаблоны буквально              | **замысел.** `Bash(git push:*)` и `Bash(git push origin:*)` — разные вещи |
| Приоритет решений фиксирован: deny > ask > allow         | **чужое**                                                                 |

## Переменные

| Что                                           | Почему                                                                      |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| Значения не шифруются                         | **замысел.** Защита — права доступа на файл; ключ шифрования лежал бы рядом |
| Секрет при правке вводится заново             | **замысел.** Панель держит только маску                                     |
| Разделения по проектам нет                    | **замысел**                                                                 |
| Нельзя увидеть, что реально дошло до процесса | **чужое.** Панель пишет файлы, а не наблюдает окружение                     |
| Секрет определяется по имени переменной       | **замысел.** Списки слов у формы и сервера совпадают не полностью           |

## Проекты

| Что                                                                         | Почему                                                                                                      |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Проектный уровень «сырой»: нет групп, выключений, health, OAuth и песочницы | **замысел.** Раздел добавлен аддитивно: правит `CLAUDE.md`, `.mcp.json` и `.claude/settings.json` проекта   |
| Проектные хуки в интерфейс не выведены                                      | **замысел.** Правятся только правила, MCP-серверы и права проекта                                           |
| Пользовательский уровень остаётся отдельным                                 | **замысел.** Разделы «Правила», «MCP» и «Права» по-прежнему ведут `~/.claude`                               |
| У прочих провайдеров проектный уровень уже                                  | **чужое.** Правится только задокументированное — состав по каждому CLI в [PROVIDERS.ru.md](PROVIDERS.ru.md) |

## Группы

| Что                                                          | Почему                                                                                                                                                                                                                              |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude о группах не знает                                    | **замысел.** Он видит только итоговые файлы                                                                                                                                                                                         |
| Сценарий не умеет больше, чем обычный хук                    | **замысел.** Он в хук и компилируется                                                                                                                                                                                               |
| Привязка к проекту группу только включает                    | **замысел.** Автовыключение снимало бы то, что человек включил сам. Совпадение считается и для параллельной копии `<репозиторий>-worktrees/<ветка>`                                                                                 |
| Порядок работы правится в группе, а не в получившемся скилле | **замысел.** Из шагов собирается `skills/scenario-…` с хуком-триггером; скилл входит в ту же группу и подчиняется её тумблеру, а неверное регулярное выражение триггера панель не сохранит — в хуке оно падало бы на каждом промпте |

## Настройки

| Что                                                          | Почему                                                                                                              |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| Восстанавливать можно только в пять известных файлов         | **замысел.** Имя копии приходит из запроса и не должно становиться путём записи                                     |
| Копии `.mcp-secrets.env` по умолчанию лежат открытым текстом | **замысел.** Есть опциональное шифрование (`encryptSecretBackups`, AES-256-GCM под паролем), по умолчанию выключено |
| Входа в аккаунт и показа токена нет                          | **замысел.** Авторизацией занимается CLI; наружу отдаётся только источник доступа                                   |

## Свой эндпоинт

| Что                                                   | Почему                                                                                                                                                                                                 |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Профиль принимают только Claude, Gemini, Qwen и Aider | **чужое.** У Codex и Continue адрес модели задаётся только в конфигурационном файле, переменной окружения для него не задокументировано; у Goose, Kimi, Cursor и OpenCode раздела переменных нет вовсе |
| Данные в запросе не маскируются                       | **замысел.** Профиль решает, КУДА уходит запрос, а не ЧТО в нём                                                                                                                                        |
| «Проверить связь» не проверяет генерацию              | **замысел.** Запрашивается только список моделей — это бесплатно; ответ модели проверяют в чате                                                                                                        |
| Токен уходит в конфигурацию CLI открытым текстом      | **чужое.** Только по явной галочке: своего хранилища секретов у чужих CLI нет                                                                                                                          |
| Уже запущенная сессия CLI об изменении не узнает      | **чужое.** Переменные окружения читаются при старте                                                                                                                                                    |

## Защита данных (локальный прокси)

| Что                                                      | Почему                                                                                                                                  |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Находит только то, что описано правилами                 | **замысел.** Это не модель и не эвристика: незаписанную фамилию не угадает, опечатку не заметит, документ во вложении не прочитает      |
| Перефразированная моделью метка обратно не подставляется | **замысел.** Восстановление идёт по точному совпадению текста; человек увидит `[ИМЯ_1]` — заметно сразу, данными не грозит              |
| Запросы Gemini не разбираются                            | **чужое.** Форма тела берётся из документации, а не угадывается; неразобранная форма по умолчанию отклоняется, а не пропускается        |
| Незнакомая форма отклоняется, а не пропускается          | **замысел.** Прокси, молча пропускающий непонятое, опаснее его отсутствия. Обратная настройка есть, каждый пропуск попадает в журнал    |
| Слушатель только на `127.0.0.1`, раздать по сети нельзя  | **замысел.** Прокси видит расшифрованные запросы вместе с ключами                                                                       |
| В журнале нет самих значений                             | **замысел.** Пишутся правило, метка и счётчик: журнал защиты данных, складывающий рядом сами данные, был бы главной дырой в этой защите |
| Словарь меток не переживает перезапуск панели            | **замысел.** Соответствие «значение → метка» живёт только в памяти и на диск не пишется                                                 |
| Сжатые ответы наверху не поддерживаются                  | **замысел.** Наверх принудительно уходит `accept-encoding: identity`: разжимать и пережимать поток ради подмены метки — лишний риск     |

## Гейт на промпте (хук)

| Что                                                       | Почему                                                                                                                                           |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Видит только набранное человеком                          | **чужое.** Событие `UserPromptSubmit` получает строку промпта; файлы, прочитанные агентом, вывод команд и промпты подагентов до него не доходят  |
| Заменить текст меткой нельзя                              | **чужое.** Событие не позволяет подменить промпт — поэтому действий два: отклонить или предупредить. Замены делает прокси                        |
| Обходится пересказом другими словами                      | **замысел.** Поиск идёт по тем же правилам, а не по смыслу: это заслон от случайной вставки, а не от намеренной отправки                         |
| Только Claude Code                                        | **чужое.** У остальных CLI события «промпт отправлен» с возможностью отказа не задокументировано                                                 |
| Непрочитанные правила и незнакомая форма входа пропускают | **замысел.** Промпт уходит с пометкой «не проверен»: скрипт, блокирующий всё подряд после смены формата, отключат в тот же день вместе с защитой |
| Правку скрипта руками панель не перезаписывает            | **замысел.** Молча затирать чужую правку в чужом конфиге нельзя; возврат своей версии — отдельная кнопка                                         |

## Телефон и удалённый доступ

| Что                                                           | Почему                                                                                                                                                                       |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Телефон не правит конфигурацию — только чат, файлы, аналитика | **замысел.** Экран телефона не место для редактора правил и хуков; объём выбран пользователем                                                                                |
| Файлы проекта на телефоне открываются на чтение               | **замысел.** Правит агент, человек смотрит; запись оставлена панели                                                                                                          |
| Пуш-уведомления не работают                                   | **чужое.** Expo Push требует `eas init` под вашим аккаунтом и проект Firebase/FCM. Пока этого нет, приложение честно говорит об этом, а локальное уведомление приходит само  |
| Связь только через собственную сеть Tailscale                 | **замысел.** Сервер остаётся на `127.0.0.1`, туннель заканчивается на вашей машине. Открывать порт наружу нельзя: единственная преграда — токен, и он рассчитан на свою сеть |
| Панель выключена — телефон не работает                        | **замысел.** Считает и запускает агентов та самая машина; облака нет, и это не забыто, а решено                                                                              |

## Другие CLI (мультипровайдерность)

Панель настраивает не только Claude Code, но честная формулировка такая: **универсально далеко не
всё.** Границы по каждому CLI вынесены отдельно —
[LIMITATIONS-PROVIDERS.ru.md](LIMITATIONS-PROVIDERS.ru.md), там же карта
[«раздел × провайдер»](LIMITATIONS-PROVIDERS.ru.md#карта-раздел--провайдер); детали форматов — в
[PROVIDERS.ru.md](PROVIDERS.ru.md).

## Поддержка систем

| Что                                           | Почему                                                                      |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| `.ps1`-хуки вне Windows требуют `pwsh`        | **чужое**                                                                   |
| Время старта агентов только на Windows        | **чужое**                                                                   |
| Учётные данные на macOS лежат в связке ключей | **чужое.** Первое обращение вызывает окно разрешения; подробности — в SETUP |

Отдельно и честно: **живьём панель прогонялась на Windows.** Ядро переносимо по построению
(`os.homedir()`, `path.join`, `\n` и `\r\n` равноправны), а платформозависимые места — имена
исполняемых файлов CLI, `where` против `which`, обёртка запуска процесса — покрыты тестами с
подменой `process.platform` на `win32`, `darwin` и `linux`. Но подмена платформы не то же самое,
что запуск на настоящей системе. Остаются непроверенными на macOS/Linux: реальный `which` и пути в
`PATH`, права `0600`/`0700` на файлах ключей, запуск CLI без обёртки `cmd.exe`, связка ключей
macOS, чувствительность файловой системы к регистру. Два теста, которым нужен настоящий POSIX
(связка ключей и `chmod 000`), помечены пропущенными, а не подделаны.
