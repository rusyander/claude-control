# Commit and MR text

1. Only commit when the user asked for it.
2. Subject: the type and the change in the imperative, under 72 characters (`fix(chat): keep draft after reload`).
3. Body: why the change was needed and what it does, in plain sentences. Mention a ticket key if the user gave one.
4. Nothing else: no authorship or attribution, no narration of how the work went, no notes to the reviewer about
   yourself.
